# Project 1 — Halaman Profil Pribadi

Ini project portfolio **pertama** kamu. Tujuannya belajar **HTML** (struktur) dan **CSS** (tampilan).

## Cara melihat hasilnya
1. Buka folder ini di File Explorer
2. Klik dua kali file `index.html` → terbuka di browser
3. Selesai! Itu sudah halaman web sungguhan

## Tugas kamu (latihan pertama)
Buka `index.html` pakai Notepad atau VS Code, lalu ubah bagian yang ditandai komentar:
- `<!-- UBAH BAGIAN INI dengan datamu -->`
- Ganti "Nama Kamu" → nama aslimu
- Ganti bio → ceritamu sendiri
- Tambah/hapus skill sesuai yang kamu punya

Simpan, lalu refresh browser. **Liat perubahannya** — itu cara belajar paling cepat.

## Konsep yang perlu kamu tahu
| Istilah | Artinya |
|---|---|
| HTML | Kerangka halaman (judul, paragraf, tombol) |
| CSS | Pengatur tampilan (warna, ukuran, posisi) |
| `<div>` | Kotak/pembungkus elemen |
| `class` | Nama label supaya CSS bisa menargetkan elemen |
